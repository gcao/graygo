# Branching evaluator version 2

The short-game deployment gate in [the design](../design.md) tests NFSP's learned average policy against complete opponent strategies. A Q best response to the current native opponent can be exploitable in the underlying mixed game. The old branching implementation also required greedy Q to have equilibrium gap at most 0.05. Its restricted tie distributions make that requirement infeasible on the unchanged mixed matrices, as the [exact certificate](../verification/uniform-costs-and-branch-gate) demonstrates.

The production evaluator now records the version graygo/nfsp-task-evaluation/2 in new run manifests, evaluation reads and results. It retains the original matrices, observations and training recipe. At each role-swapped root it computes both the best observable response value and the candidate greedy-Q value against the same current native episode mixture. It first marginalizes the hidden opponent component, then maximizes; public moves update its posterior. Selecting a best response separately for each hidden component would leak unavailable information.

The explicit [version-two grade](../experiments/nfsp-branch-grading-v2.json) requires, for all original seeds and every final-five evaluation, average-policy equilibrium gap at most 0.05, greedy native-response gap at most 0.05, and supported native value error at most 0.10. This response definition and its proposed fixed thresholds were frozen in the earlier diagnostic specification before its new metric was computed. Legacy greedy equilibrium gaps remain in public evaluations and result summaries as diagnostics. Delayed-credit and bounded Gray Go grades are unchanged.

The three original neural runs remain historical version-one cases and misses. Their [read-only diagnostic](../verification/nfsp-branching-neural-seeds012-final/native-response/diagnostic.json) also misses all three version-two response limits; average/value limits miss as well. No run is retroactively converted into a passing case.

This code correction is a new source identity. The original frozen training/auditor processes continue using their exact original packages. Existing version-one cohort plans/collectors and compatibility receipts do not admit this new source or grading protocol. A version-two source/evidence bridge, independent case collector and matched controls are still required before any protocol exit; this change selects no new training or 9x9 pilot. The fixed all-seed/final-five requirements remain.

Regression coverage includes an analytical native-response fixture with calibrated Q values and a non-Nash greedy policy, hidden-type versus public-action information, an independent complete-strategy enumeration, invalid probability/node-limit failures, and bit-exact neural checkpoint resume. Read-only production validation compares all ninety original archives against the frozen independent enumeration and reproduces every legacy root metric.
